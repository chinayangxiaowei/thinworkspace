### 实施顺序与旧路线处置

1. 先以失败测试证明源 `.git` 被拒绝和旧目标控制项前提；移除该前提，统一使用空目标、全树 manifest 和登记对象回滚。旧“保护 `.git`”断言改为普通非空目标拒绝/树外 sentinel 保护；不保留旧兼容开关。
2. 再以失败测试补普通文件、嵌套目录及源根目录 mtime；两后端显式满足同一范围，源变化不能误报成功。
3. 补其余原始目录/失败边界并执行专项门禁，审核后真实 release 验证；全任务退出条件未满足前不标 Done。

旧 P0-03 未合并代码和 18 项未提交输入留在原工作区与分支，新基线没有导入它们；main 的 Cargo/CI/fuzz 配置原样保留，不以删除测试消除失败。P0-02 的 Git sentinel 前提已被 ADR-0002 替代，但其身份校验、未知项停止、CoW 与显式降级安全断言继续保留并回归。历史实验记录不改写为本任务证据。

## 验收断言

| 场景 | 可检查的结果 |
|---|---|
| 非 Git 源与完整内容 | 两后端都物化嵌套普通文件、`.git` 目录/普通指针文件、ignored/未跟踪命名、构建产物；按磁盘内容复制，不调用 Git、不筛选名称 |
| 非空目标 | 包括预建 `.git` 在内的任意既有条目均拒绝，既有内容不变；无隐藏控制项豁免 |
| mtime/权限 | 普通文件、嵌套目录、空目录与源根目录按源实际时间精度比较；目录在子项完成后恢复权限和 mtime；不宣称其他元数据或缓存命中保证 |
| 链接与硬链接 | symlink 文本原样复制，不访问树外目标；普通硬链接目录项成为独立副本，目标写入不改变源及其他目标副本 |
| 空树与无普通文件 | 创建成功、CoW not-used；包含普通文件且全部真实克隆成功并校验后才 confirmed |
| 源变化与布局 | 源/目标重叠拒绝；在已验证观察边界修改源内容、结构或受保证元数据时拒绝成功；证明可发现的变化，不称为原子快照 |
| 特殊项/子挂载 | 明确失败且不静默跳过，不克隆或清理挂载外数据；真实环境未准备时记录未执行 |
| 回滚与未知对象 | `.git` 与其他已登记条目同样回滚；完整身份集不符、登记失败或回滚失败时保留现场；树外 sentinel/指针目标不变 |
| 回归 | 同卷真实 clone、跨卷 EXDEV、显式 Full Copy、不允许降级的 errno、未知项停止与重复扫描等 P0-02 安全覆盖仍通过 |

## 运行与清理边界
